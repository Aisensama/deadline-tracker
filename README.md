# 📚 Deadline Tracker

Deadline Tracker is an AI-powered Streamlit application that extracts academic deadlines from uploaded images using Google Gemini.

## What the app does

- Upload a syllabus, timetable, assignment sheet, or similar document image.
- Gemini analyzes the image and extracts important deadlines.
- Deadlines are displayed in a structured dashboard.
- Duplicate deadlines are detected and avoided.
- Deadlines are organized chronologically.
- A deadline summary can be sent to Telegram.

## Tech Stack

- Python
- Streamlit
- Google Gemini
- Telegram Bot API
- python-telegram-bot
